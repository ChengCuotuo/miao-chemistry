# Miao教学管理系统

## 项目简介

Miao教学管理系统是一个基于Electron + Vue 3开发的桌面应用程序，主要面向教师和教育工作者，提供班级小组积分管理、互动游戏等功能，帮助教师更好地管理课堂活动和激励学生。

### 主要功能模块

1. **小组积分管理系统**
   - 班级管理（创建、编辑、删除、导入导出）
   - 学生管理（单个/批量新增、编辑删除、随机点名、记录查看、搜索排序）
   - 分组管理（创建编辑删除、成员管理、积分调整、批量操作、排序调整）
   - 规则设置（自定义积分规则、规则导入导出、搜索筛选）
   - 奖品管理（奖品设置、图片上传编辑、库存管理、搜索筛选）
   - 积分兑换（学生积分兑换奖品、二次确认、自动记录）
   - 积分记录（详细记录查询、多条件筛选、分页查看）
   - 基础设置（密码管理、积分步长设置）
   - 系统功能（全屏模式、模块切换）

2. **互动游戏**
   - 推箱子游戏（多关卡挑战、计时计步）

- Windows 10及以上

## 安装步骤

### 1. 克隆项目

```bash
git clone <项目地址>
cd miao-chemistry
```

### 2. 安装依赖

```bash
npm install
```

### 3. 启动开发服务器

```bash
npm start
```

### 4. 打包应用

```bash
# Windows平台
npm run build:win

# macOS平台  
npm run build:mac

# 全平台打包
npm run build:all
```

## 使用说明

### 首次启动

1. 启动应用后，进入主界面
2. 点击"新增班级"卡片创建第一个班级
3. 输入班级名称，点击确定

### 班级管理

#### 创建班级

- 点击首页的"+"卡片
- 输入班级名称
- 点击"确定"完成创建

#### 编辑班级

- 点击班级卡片上的编辑图标
- 修改班级名称
- 点击"确定"保存修改

#### 删除班级

- 点击班级卡片上的删除图标
- 确认删除操作

#### 导入班级

- 点击右下角的导入按钮
- 选择之前导出的班级数据文件
- 确认导入

#### 导出班级

- 点击班级卡片上的下载图标
- 选择保存位置
- 班级数据将以加密格式导出

### 学生管理

#### 添加学生

**单个新增**

1. 进入班级详情页面
2. 切换到"学生列表"标签
3. 点击"新增学生"按钮
4. 输入学生姓名和初始积分
5. 点击确定完成添加

**批量新增**

1. 在学生列表页面
2. 点击"批量新增"按钮
3. 支持两种导入方式：
   - **TXT文件**：每行一个学生姓名，支持中文逗号或分号分隔
   - **Excel文件**：下载模板，按模板格式填写姓名和积分
4. 可在导入前编辑学生信息和积分
5. 支持统一修改所有学生的积分值
6. 点击提交完成批量添加

#### 编辑学生

- 点击学生列表中的"编辑"按钮
- 修改学生姓名和积分
- 点击确定保存修改

#### 删除学生

- 点击学生列表中的"删除"按钮
- 确认删除操作

#### 随机点名

1. 在学生列表页面
2. 点击"随机点名"按钮
3. 点击"开始点名"进行随机抽取
4. 系统显示动画效果，随机滚动学生姓名
5. 最终显示被选中的学生姓名和学号

#### 查看学生记录

- 点击学生列表中的"记录"按钮
- 查看该学生的详细积分变动记录
- 支持按规则、时间等条件筛选

#### 学生搜索和排序

- 支持按姓名或ID搜索学生
- 支持按积分升序或降序排序
- 支持分页查看学生列表（10/30/60条每页）

### 分组管理

#### 创建分组

1. 进入班级详情页面
2. 切换到"分组列表"标签
3. 点击"新增小组"按钮
4. 输入分组名称
5. 从学生列表中选择成员（支持搜索过滤）
6. 点击确定完成创建

#### 编辑分组

- 点击分组卡片上的编辑按钮
- 修改分组名称和成员
- 点击确定保存修改

#### 删除分组

- 点击分组卡片上的删除按钮
- 确认删除操作

#### 调整排序

1. 在分组列表页面
2. 点击"调整排序"按钮
3. 选择排序方式：
   - **根据总积分排序**：按小组总积分自动排序
   - **自定义排序**：拖拽调整分组顺序
4. 点击确定完成排序

#### 小组搜索

- 支持按小组名称或学生姓名搜索
- 快速定位需要操作的小组

#### 小组成员管理

- 在分组卡片中可查看所有成员
- 支持搜索特定成员
- 显示每个成员的当前积分

#### 单个学生积分调整

**快速加减分**

- 点击学生旁边的绿色按钮（+）按步长加分
- 点击学生旁边的红色按钮（-）按步长减分
- 积分变化自动记录

**按规则调整**

- 点击学生旁边的黄色按钮（票券图标）
- 从规则列表中选择要应用的规则
- 查看规则描述和积分值
- 确认后按规则调整学生积分

**查看学生记录**

- 点击学生积分标签
- 查看该学生的详细积分变动记录

#### 批量积分调整

**批量加减分**

1. 在分组卡片底部
2. 点击绿色按钮（+）批量加分
3. 点击红色按钮（-）批量减分
4. 输入要调整的积分值
5. 确认后为小组所有成员调整积分

**批量按规则调整**

1. 在分组卡片底部
2. 点击黄色按钮（票券图标）
3. 从规则列表中选择要应用的规则
4. 确认后为小组所有成员按规则调整积分

#### 分组信息显示

- 每个分组卡片显示小组总积分
- 实时更新积分变化
- 显示小组成员数量

### 规则设置

#### 创建规则

1. 进入"规则设置"页面
2. 点击"新增规则"按钮
3. 填写规则信息：
   - 规则名称
   - 积分值（正数为加分，负数为减分）
   - 适用班级（留空表示所有班级）
   - 规则描述
4. 点击确定保存规则

#### 编辑规则

- 点击规则列表中的"编辑"按钮
- 修改规则信息
- 点击确定保存修改

#### 删除规则

- 点击规则列表中的"删除"按钮
- 确认删除操作

#### 规则搜索和筛选

- 支持按规则名称搜索
- 支持按规则类型筛选（加分规则/减分规则）
- 支持按适用班级筛选
- 支持分页查看规则列表（10/30/60条每页）

#### 规则导入

1. 在规则设置页面
2. 点击"导入"按钮
3. 选择之前导出的规则文件（加密格式）
4. 系统自动解密并导入规则
5. 显示导入成功和失败的数量

#### 规则导出

1. 在规则设置页面
2. 点击"导出"按钮
3. 选择保存位置
4. 规则数据将以加密格式导出

#### 规则显示

- 积分值用颜色标识（绿色为加分，红色为减分）
- 显示规则序号（前8位）
- 显示适用班级信息

### 奖品设置

#### 添加奖品

1. 进入"奖品设置"页面
2. 点击"新增奖品"按钮
3. 填写奖品信息：
   - 奖品名称
   - 积分值（兑换所需积分）
   - 奖品数量
   - 适用班级（留空表示所有班级）
   - 上传奖品图片（支持裁剪和压缩）
   - 奖品描述
4. 点击确定保存奖品

#### 编辑奖品

- 点击奖品列表中的"编辑"按钮
- 修改奖品信息
- 可以更换或编辑奖品图片
- 点击确定保存修改

#### 删除奖品

- 点击奖品列表中的"删除"按钮
- 确认删除操作

#### 奖品搜索和筛选

- 支持按奖品名称搜索
- 支持按适用班级筛选
- 支持分页查看奖品列表（10/30/60条每页）
- 点击图片可预览大图

#### 奖品库存管理

- 实时显示奖品库存状态
- 库存充足：绿色标签
- 库存紧张：黄色标签（<10）
- 库存不足：红色标签（0）

#### 奖品图片管理

- 支持上传本地图片
- 支持图片裁剪和压缩
- 自动优化图片大小
- 编辑时可更换图片

### 积分兑换

#### 发起兑换

1. 进入班级详情页面
2. 切换到"积分兑换"标签
3. 查看可用奖品列表（仅显示有库存的奖品）
4. 点击"兑换"按钮选择要兑换的奖品
5. 查看奖品详情（图片、名称、所需积分、剩余数量）
6. 系统自动筛选积分足够的学生
7. 支持按学生姓名搜索
8. 点击选择要兑换的学生
9. 点击"确认竞拍"进行二次确认
10. 确认后完成兑换：
    - 学生积分相应扣除
    - 奖品库存减少
    - 自动生成积分扣除记录

#### 兑换限制

- 只有积分足够的学生才能参与兑换
- 每次只能选择一个学生进行兑换
- 库存为0的奖品无法兑换

#### 查看兑换记录

- 积分兑换会自动生成积分扣除记录
- 在积分记录中可以查看兑换详情
- 点击兑换记录中的问号图标可查看奖品详情
- 记录标识为"积分兑换"

### 积分记录

#### 查看记录

1. 进入班级详情页面
2. 切换到"积分记录"标签
3. 查看所有积分变动记录
4. 支持按学生ID、学生姓名、规则名称等条件筛选
5. 支持按积分类型筛选（加分/减分）
6. 支持分页查看记录

### 基础设置

#### 积分步长设置

1. 进入"基础设置"页面
2. 在"步长设置"区域调整数值
3. 设置范围：1-10分
4. 系统自动保存设置（防抖处理）

- 影响快速加减分的积分变化量
- 建议根据实际教学需求设置合适的步长值

#### 修改密码

1. 进入"基础设置"页面
2. 点击密码输入框旁的编辑按钮
3. 输入原密码和新密码
4. 点击确定完成修改

- 密码采用MD5加密存储
- 确保数据安全

## 数据管理

### 数据存储

- 所有数据存储在本地用户目录
- 数据文件经过加密处理，确保数据安全
- 支持手动备份和恢复
- 图片资源单独存储，支持压缩优化

### 数据备份

1. 在班级管理页面
2. 点击班级的下载按钮
3. 选择保存位置
4. 班级数据将以加密格式导出
5. 完成备份

### 数据恢复

1. 点击右下角的导入按钮
2. 选择之前备份的加密文件
3. 系统自动解密并验证数据
4. 确认导入信息
5. 完成数据恢复

### 数据安全

- 所有敏感数据都经过AES加密
- 导出文件使用专用格式，无法直接查看
- 支持密码保护功能
- 定期建议用户进行数据备份

## 常见问题

### Q: 应用无法启动？

A: 请检查Node.js版本是否满足要求（>=16.0.0），重新安装依赖：`npm install`

### Q: 数据丢失怎么办？

A: 如果有备份文件，可以通过导入功能恢复数据。建议定期进行数据备份。

### Q: 如何重置应用？

A: 删除用户目录下的应用数据文件夹，重新启动应用即可重置所有数据。

### Q: 支持多班级管理吗？

A: 支持，可以创建多个班级，每个班级独立管理学生、分组和积分。

### Q: 数据是否安全？

A: 所有数据都经过AES加密存储，导出文件也使用加密格式，确保数据安全。

### Q: 支持数据同步吗？

A: 目前版本不支持云端同步，但支持导入导出功能，可以手动在不同设备间传输数据。

### Q: 如何更新应用？

A: 下载最新版本安装包，覆盖安装即可。数据会自动保留。

### Q: 奖品图片支持什么格式？

A: 支持常见图片格式（JPG、PNG等），系统会自动进行压缩和优化处理。

### Q: 积分兑换后可以撤销吗？

A: 目前版本不支持撤销操作，请在兑换前仔细确认信息。

### Q: 推箱子游戏有多少关卡？

A: 游戏包含多个精心设计的关卡，难度逐渐递增，适合不同水平的玩家。
