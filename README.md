# Miao积分管理系统 - 操作手册

## 项目简介

Miao积分管理系统是一个基于Electron + Vue 3开发的桌面应用程序，主要面向教师和教育工作者，提供班级小组积分管理功能。

### 主要功能模块

1. **小组积分管理系统**
   - 班级管理
   - 学生管理  
   - 分组管理
   - 积分规则设置
   - 奖品管理
   - 积分兑换
   - 数据导入导出

2. **互动游戏**
   - 推箱子小游戏

## 环境要求

### 开发环境

- **Node.js**: >= 16.0.0
- **npm**: >= 8.0.0
- **操作系统**: Windows/macOS/Linux

### 运行环境

- Windows 10及以上
- macOS 10.13及以上
- Linux（主流发行版）

## 安装步骤

### 1. 克隆项目

```bash
git clone <项目地址>
cd miao-chemistry
```

### 2. 安装依赖

```bash
npm install
```

### 3. 启动开发服务器

```bash
npm start
```

### 4. 打包应用

```bash
# Windows平台
npm run build:win

# macOS平台  
npm run build:mac

# 全平台打包
npm run build:all
```

## 使用说明

### 首次启动

1. 启动应用后，进入主界面
2. 点击"新增班级"卡片创建第一个班级
3. 输入班级名称，点击确定

### 班级管理

#### 创建班级

- 点击首页的"+"卡片
- 输入班级名称
- 点击"确定"完成创建

#### 编辑班级

- 点击班级卡片上的编辑图标
- 修改班级名称
- 点击"确定"保存修改

#### 删除班级

- 点击班级卡片上的删除图标
- 确认删除操作

#### 导入班级

- 点击右下角的导入按钮
- 选择之前导出的班级数据文件
- 确认导入

#### 导出班级

- 点击班级卡片上的下载图标
- 选择保存位置
- 班级数据将以加密格式导出

### 学生管理

#### 添加学生

1. 进入班级详情页面
2. 切换到"学生列表"标签
3. 点击"批量新增"按钮
4. 输入学生姓名（每行一个）
5. 点击确定完成添加

#### 随机点名

1. 在学生列表页面
2. 点击"随机点名"按钮
3. 系统将随机选择一名学生

### 分组管理

#### 创建分组

1. 进入班级详情页面
2. 切换到"分组列表"标签
3. 点击"新增分组"按钮
4. 输入分组名称
5. 从学生列表中选择成员
6. 点击确定完成创建

#### 积分管理

1. 点击分组卡片
2. 选择要应用的规则
3. 输入积分值
4. 点击确定完成积分调整

#### 批量积分

1. 在分组列表页面
2. 点击"批量积分"按钮
3. 选择要调整的分组
4. 设置积分值
5. 点击确定完成批量调整

### 规则设置

#### 创建规则

1. 进入"规则设置"页面
2. 点击"新增规则"按钮
3. 填写规则信息：
   - 规则标题
   - 规则说明
   - 积分值（正数为加分，负数为减分）
   - 适用班级
4. 点击确定保存规则

#### 管理规则

- 编辑：点击规则卡片上的编辑按钮
- 删除：点击规则卡片上的删除按钮
- 导入导出：支持规则的批量导入导出

### 奖品设置

#### 添加奖品

1. 进入"奖品设置"页面
2. 点击"新增奖品"按钮
3. 填写奖品信息：
   - 奖品名称
   - 库存数量
   - 上传奖品图片（支持裁剪和压缩）
   - 适用班级
4. 点击确定保存奖品

#### 管理奖品

- 编辑：点击奖品卡片上的编辑按钮
- 删除：点击奖品卡片上的删除按钮
- 查看详情：点击奖品卡片查看详细信息

### 积分兑换

#### 发起兑换

1. 进入班级详情页面
2. 切换到"积分兑换"标签
3. 选择要兑换的奖品
4. 设置兑换积分
5. 学生使用积分进行兑换
6. 兑换成功后，学生将获得奖品

#### 查看兑换记录

- 在积分兑换页面可以查看历史兑换记录
- 支持按时间、学生等条件筛选

### 积分记录

#### 查看记录

1. 进入班级详情页面
2. 切换到"积分记录"标签
3. 查看所有积分变动记录
4. 支持按学生、规则、时间等条件筛选

#### 导出记录

- 点击"导出"按钮
- 选择导出格式
- 保存到本地

### 基础设置

#### 修改密码

1. 进入"基础设置"页面
2. 点击"修改密码"按钮
3. 输入原密码和新密码
4. 点击确定完成修改

#### 积分步长设置

- 设置积分调整的最小单位
- 影响积分加减的精度

## 数据管理

### 数据存储

- 所有数据存储在本地用户目录
- 数据文件经过加密处理
- 支持手动备份和恢复

### 数据备份

1. 在班级管理页面
2. 点击班级的下载按钮
3. 选择保存位置
4. 完成备份

### 数据恢复

1. 点击右下角的导入按钮
2. 选择备份文件
3. 确认导入
4. 完成恢复

## 快捷键

### 通用快捷键

- `Cmd/Ctrl + Q`: 退出应用
- `Cmd/Ctrl + ,`: 打开设置

### 页面快捷键

- `Esc`: 关闭当前对话框
- `Enter`: 确认当前操作

## 常见问题

### Q: 应用无法启动？

A: 请检查Node.js版本是否满足要求，重新安装依赖。

### Q: 数据丢失怎么办？

A: 如果有备份文件，可以通过导入功能恢复数据。

### Q: 如何重置应用？

A: 删除用户目录下的应用数据文件夹，重新启动应用。

### Q: 支持多班级管理吗？

A: 支持，可以创建多个班级，每个班级独立管理。

### Q: 数据是否安全？

A: 所有数据都经过加密存储，确保数据安全。

### Q: 支持数据同步吗？

A: 目前版本不支持云端同步，但支持导入导出功能。

### Q: 如何更新应用？

A: 下载最新版本安装包，覆盖安装即可。
