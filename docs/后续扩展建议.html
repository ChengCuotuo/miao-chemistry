功能扩展路线图 · 班主任 / 教育专家视角

从「积分工具」到「班级成长系统」

三条主线、四个阶段，让功能扩展有方向、有顺序、有教育逻辑

主线 A · 升维评价

积分 → 成长档案。从"行为加减分"升级为"五育并举、增值评价、成长记录"。

主线 B · 扩主体

教师 → 学生 / 家长 / 科任。从"教师一人记分"走向"多方参与、家校协同"。

主线 C · 强洞察

记录 → 智能。从"数据登记"走向"预警、建议、自动生成报告"。

1四个扩展阶段

阶段一 · 成长评价系统

近期 · 价值最高
把「积分」升维成「成长」，直接解决上一轮指出的"外在激励依赖、只记行为不记成长"问题。
  • 五育多维评价 — 从单一行为积分扩展到德（品德/助人）、智（参与/进步）、体（两操/体育）、美（活动/作品）、劳（值日/卫生），维度可自定义。
  • 增值评价 / 进步曲线 — 不只显示绝对分，突出"本期比上期进步 X"，关注与自己的比较而非横向排名。
  • 闪光点 / 正向记录 — 独立于加减分的"表扬墙"、好人好事记录，让正向信号盖过减分。
  • 学期成长报告 — 一键生成学生个人 + 班级整体报告，可导出 PDF / 分享家长。

阶段二 · 多方参与

中期 · 生态关键
评价若只有教师一个主体，就只是"管理工具"；引入学生和家长，才变成"成长共同体"。
  • 家长端（微信小程序 / 网页） — 接收周报、表扬通知、请假申请，查看孩子成长档案。
  • 学生端 — 自评互评、个人目标卡（"本周我想达成…"）、习惯打卡。
  • 科任教师协同 — 多教师账号，按学科/场景记分，数据汇总到班主任。

阶段三 · 班主任运营工具包

中期 · 提高粘性
把班主任每天手忙脚乱的"杂活"数字化，让系统成为离不开的日常工具。
  • 座位表编排 — 拖拽编排，可按积分异质/同质分组，一键生成。
  • 值日 / 卫生排班 — 轮值表自动生成 + 到期提醒。
  • 考勤 / 请假 — 请假审批、缺勤记录。
  • 班级日志 / 大事记 — 按天记录，学期末生成班级纪念册。
  • 班会素材库 — 主题班会模板、活动方案。

阶段四 · 数据智能 + 生态

远期 · 护城河
数据积累到一定程度后，用智能能力把教师从"看数据"解放到"做判断"。
  • 智能建议引擎 — 基于数据生成"下周班级管理建议"（如"XX 连续两周下滑，建议单独谈心"）。
  • 异常预警 — 情绪 / 低分 / 缺勤异常提醒，主动关怀而非事后追责。
  • 规则 / 模板市场 — 教师间共享优质规则、奖品、班会方案。
  • 跨学期归档 / 毕业档案 — 毕业时生成"学生成长档案"，随学籍移交。

2落地优先级

批次功能为什么先做
第一批闪光点记录 · 进步值 · 学期报告 · 家长周报直接解决"激励温度"与"家校断裂"，且集中在现有数据分析层，工程成本可控、见效最快
第二批学生端（自评互评 / 目标卡）· 座位表参与主体扩展 + 高频刚需，能显著提升使用频率
第三批五育多维 · 科任协同 · 智能建议需要重构数据模型，价值大但成本高，宜在数据积累后做
远期模板市场 · 毕业成长档案依赖用户规模与数据沉淀，属于生态型功能

3四条设计原则（做之前先想清楚）

每个功能先回答"学生成长了什么"

回答不了的功能，再炫也不做。

正向优先

表扬、闪光点、进步要始终盖过减分和排名。

隐私边界

家长端、学生端只看自己（孩子）的数据，不做横向公开比较。

教师零负担

自动化生成，减轻而非加重记录负担。

结论：扩展的正确顺序是「先补温度、再扩主体、后上智能」。第一批功能（闪光点、进步值、学期报告、家长周报）投入产出比最高，建议优先立项。
